# Test MoMo/VNPay With Local Backend

Use a public HTTPS tunnel when MoMo or VNPay needs to call the local backend return/IPN URLs.

## Cloudflare Tunnel

Backend:

```powershell
cloudflared tunnel --url http://localhost:8080
```

Optional frontend tunnel, only needed when testing from another device:

```powershell
cloudflared tunnel --url http://localhost:4200
```

## Backend Environment

Run the Spring Boot app with:

```powershell
$env:APP_PUBLIC_API_BASE_URL = "https://<backend-tunnel-domain>"
$env:APP_FRONTEND_BASE_URL = "http://localhost:4200"
$env:APP_CORS_ORIGINS = "http://localhost:4200,https://<frontend-tunnel-domain>"
$env:VNPAY_TMN_CODE = "<vnpay-tmn-code>"
$env:VNPAY_HASH_SECRET = "<vnpay-hash-secret>"
$env:MOMO_PARTNER_CODE = "<momo-partner-code>"
$env:MOMO_ACCESS_KEY = "<momo-access-key>"
$env:MOMO_SECRET_KEY = "<momo-secret-key>"
```

If the frontend is also opened through a tunnel, set:

```powershell
$env:APP_FRONTEND_BASE_URL = "https://<frontend-tunnel-domain>"
```

## Callback URLs

VNPay:

```text
https://<backend-tunnel-domain>/api/payments/vnpay/return
https://<backend-tunnel-domain>/api/payments/vnpay/ipn
```

MoMo is generated by the backend from `APP_PUBLIC_API_BASE_URL`:

```text
https://<backend-tunnel-domain>/api/payments/momo/return
https://<backend-tunnel-domain>/api/payments/momo/ipn
```

## Testing Note

When scanning a QR code on a phone, the payment gateway may open the result page on the phone. The backend IPN can still update the order, but the phone browser may not have the customer login token. The most reliable local check is to return to the desktop browser and inspect `/account/orders`.
